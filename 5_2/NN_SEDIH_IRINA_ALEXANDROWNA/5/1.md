# Свёрточные нс
Высокая точность распознавания изображений.
Обычные сети с прямым распространением сигнала
256x256 растянем в один вектор - у многослойного перцептрона
кол-во параметров сильно возрастает (геометрически).

2. Работают с матрицами (изображения). А многослойные перцептроны работают с
   векторами.

тензор - матрица массивов чисел (3D-матрица)

свертка - применяется к 2м функциям, возвращает третью функцию с помощью интеграла.
g - ядро или функция-фильтр

паттерн - ... + активируется при опред. значении входных данных.
ядро - маленький шаблон.
карта активации показывает насколько похож сигнал на шаблон.
считается как

отступ (padding) - насколько отступить от границ массива и заполнить отступы значениями.
шаг (stride) - перескок через n элементов - позволяет уменьшить размерность массива -> работы.
расширение (dilation) - один результат применить к нескольким элементам.

Сверточный слой ищет паттерн. По карте признаков видно какие паттерны найдены.
Сверточные сети работают с тензорными.
Сколько паттернов, столько и слоев.

Выходные данные - выходной тензор.

3 - 32 сколкьо каналов, столько и фильтров.

Свертка - группировка группы 1 (полная связность вход-выход)
