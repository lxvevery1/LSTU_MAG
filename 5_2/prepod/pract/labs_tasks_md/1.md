ЛАБОРАТОРНАЯ РАБОТА №1

Тема: Основы языка разметки HTML. Вёрстка веб-страницы.

Цель работы
Изучить основы языка разметки HTML, освоить структуру HTML-документа, познакомиться с основными тегами и их атрибутами. Получить практические навыки вёрстки веб-страницы на примере воссоздания статьи из Википедии.
Задание кафедры
Используя знания по HTML, выбрать любую страницу на Википедии (wikipedia.org) и сверстать её. Страница должна быть воссоздана самостоятельно с помощью HTML-кода и визуально соответствовать оригинальной статье.

Требования к выполнению задания:
    1. Выбранная статья должна содержать разнообразные элементы: заголовки разных уровней, абзацы текста, списки (маркированные и/или нумерованные), таблицы, изображения, гиперссылки.
    2. HTML-код должен быть написан самостоятельно. Копирование исходного кода страницы Википедии не допускается.
    3. Страница должна корректно отображаться в современном браузере (Google Chrome, Mozilla Firefox, Microsoft Edge и др.).
    4. Файл с расширением .html должен быть сохранён и предоставлен вместе с отчетом.

Требования к отчёту
Отчёт по лабораторной работе должен содержать следующие разделы:
    1. Титульный лист
    2. Цель работы
    3. Задание кафедры
    4. Краткая теоретическая информация по теме - описание основных понятий HTML: что такое теги, атрибуты, структура HTML-документа, назначение основных элементов (заголовки, абзацы, списки, таблицы, ссылки, изображения).
    5. Выполнение работы - изображение выбранной статьи, скриншоты результата верстки в браузере, листинг HTML-кода.
    6. Вывод
