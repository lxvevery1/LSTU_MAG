ЛАБОРАТОРНАЯ РАБОТА №2
Тема: Разработка статической веб-страницы. Верстка макета из Figma в
HTML/CSS, создание диаграммы вариантов использования (Use-case
Diagram).
Цель работы
Изучить и применить на практике современные методы верстки веб-
страниц. Освоить процесс конвертации графического макета (дизайна) в
работающий HTML/CSS код. Научиться работать с CSS-свойствами для
позиционирования элементов, стилизации текста и создания адаптивных
блоков. Применить на практике полученные знания для изображения
диаграммы вариантов использования (Use-case Diagram)
Задание кафедры
Используя знания HTML и CSS, сверстать страницу по одному из
макетов в Figma. Студент получает вариант в соответствии со своим номером
в списке группы. Готовая веб-страница должна полностью соответствовать
макету: соблюдена цветовая гамма, размеры и гарнитура шрифтов, отступы
между блоками (margin/padding), а также состояние элементов при наведении
(hover), если оно предусмотрено дизайном. Все ресурсы (изображения,
иконки) необходимо экспортировать из Figma самостоятельно. Изобразить
диаграмму вариантов использования (Use-case Diagram) для своего варианта.
Требования к выполнению задания:
1. Структура и контент: Макет должен содержать разнообразные
элементы: заголовки разных уровней, абзацы текста, списки
(маркированные и/или нумерованные), таблицы, изображения, кнопки
и гиперссылки.
2. Самостоятельность кода: HTML и CSS код должен быть написан
самостоятельно. Копирование сгенерированного кода из Figma или
использование готовых решений (библиотек, фреймворков) для
верстки всего макета не допускается.
3. Валидность и кроссбраузерность: Верстка должна быть семантической
(использование тегов <header>, <main>, <section>, <footer> и т.д.).
Страница должна корректно отображаться в современном браузере
(Google Chrome, Mozilla Firefox, Microsoft Edge).
4. Адаптивность (опционально, по усмотрению преподавателя): При
изменении ширины окна браузера контент не должен "разваливаться"
(можно добавить минимальное требование по резиновости или
фиксации).
5. Готовая работа должна содержать HTML-файл и папку с ресурсами
(CSS-стили, изображения) и предоставлена вместе с отчетом.
Требования к отчёту
Отчёт по лабораторной работе должен содержать следующие разделы:
1. Титульный лист
2. Цель работы
3. Задание кафедры
4. Краткая теоретическая информация по теме - описание основных
понятий HTML, CSS, Use-case.
5. Выполнение работы - скриншоты результата верстки в браузере,
листинг HTML и CSS кода, диаграмма вариантов использования (Use-
case Diagram)
6. Вывод
