ЛАБОРАТОРНАЯ РАБОТА №3

Тема: Разработка статической веб-страницы. Верстка макета из Figma в HTML/CSS с применением стиля “Grid”, создание диаграмм кооперации и развертывания.

Цель работы
	Изучить методы верстки статических веб-страниц, освоить преобразование макета из Figma в HTML/CSS-код с использованием CSS Grid, а также приобрести навыки построения UML-диаграмм кооперации для описания взаимодействия компонентов веб-страницы.
Задание кафедры
	Используя знания по HTML и CSS, сверстать статическую веб-страницу по одному из макетов, разработанных в среде Figma. Номер варианта определяется в соответствии с номером студента в списке группы.

Требования к выполнению задания:
    1. Веб-страница должна быть сверстана по предоставленному макету из среды Figma и содержать разнообразные элементы интерфейса: заголовки различных уровней, абзацы текста, списки (маркированные и/или нумерованные), изображения, кнопки, гиперссылки и другие элементы, предусмотренные макетом.
    2. Верстка страницы должна быть выполнена с использованием HTML5 и CSS3 с применением технологии CSS Grid для организации структуры и расположения основных блоков страницы.
    3. Все графические ресурсы (изображения, иконки и другие элементы интерфейса) должны быть самостоятельно экспортированы из макета Figma и корректно подключены в проекте.
    4. Веб-страница должна корректно отображаться в современных браузерах (Google Chrome, Mozilla Firefox, Microsoft Edge и др.).
    5. Дополнительно должна быть разработана UML-диаграмма кооперации, отражающая взаимодействие пользователя, браузера и веб-сервера при загрузке веб-страницы и связанных ресурсов.
    6. Файлы проекта (HTML- и CSS-файлы, а также используемые ресурсы) должны быть сохранены и предоставлены вместе с отчетом по лабораторной работе.
Требования к отчёту
Отчёт по лабораторной работе должен содержать следующие разделы:
    1. Титульный лист
    2. Цель работы
    3. Задание кафедры
    4. Краткая теоретическая информация по теме – описание Grid layout, диаграммы кооперации и диаграммы развертывания.
    5. Выполнение работы – скриншоты результата верстки в браузере, листинг HTML- и CSS-кода, диаграмма кооперации, диаграмма развертывания.
    6. Вывод
