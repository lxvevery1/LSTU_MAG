ЛАБОРАТОРНАЯ РАБОТА №5
Тема: Разработка веб-страницы с парсингом данных на JavaScript.
Цель работы
Изучить методы получения и обработки данных с внешних
веб-ресурсов с помощью JavaScript, освоить технологии fetch API и
работу с JSON-данными, а также приобрести навыки построения
веб-страниц, динамически отображающих полученные данные.
Задание кафедры
Используя знания по HTML, CSS и JavaScript, разработать
веб-страницу, которая осуществляет парсинг (получение) данных с
любого публично доступного сайта или API, и отображает эти данные в
виде структурированного, визуально оформленного интерфейса.
Требования к выполнению задания:
1. Выбрать любой публично доступный сайт или открытый API
(например: новостные сайты, каталоги фильмов, погодные
сервисы, курсы валют, спортивная статистика и т.д.) в качестве
источника данных для парсинга.
2. Реализовать получение данных с выбранного источника с
помощью JavaScript (fetch API или XMLHttpRequest). При
необходимости использовать CORS-прокси для обхода
ограничений браузера.
3. Полученные данные должны быть обработаны и динамически
отображены на веб-странице без перезагрузки страницы (без
использования серверных технологий).
4. Вёрстка страницы должна быть выполнена с использованием
HTML5 и CSS3 с применением технологии CSS Grid или Flexbox
для организации структуры отображаемых данных.
5. Веб-страница должна корректно отображаться в современных
браузерах (Google Chrome, Mozilla Firefox, Microsoft Edge и др.).
6. Файлы проекта (HTML-, CSS- и JS-файлы) должны быть
сохранены и предоставлены вместе с отчётом по лабораторной
работе.
Требования к отчёту
Отчёт по лабораторной работе должен содержать следующие
разделы:
1. Титульный лист
2. Цель работы
3. Задание кафедры
4. Краткая теоретическая информация по теме – описание fetch
API, принципов работы с JSON, понятие CORS и способы его
обхода, основы динамического обновления DOM.
5. Выполнение работы – описание выбранного источника данных,
скриншоты результата работы веб-страницы в браузере, листинг
HTML-, CSS- и JavaScript-кода, диаграмма компонентов,
диаграмма развёртывания.
6. Вывод
Задание
Взять данные для парсинга с любого сайта и под эти данные
сверстать сайт. Парсить с помощью JavaScript.
Дополнительно необходимо разработать следующие
UML-диаграммы:
1. Диаграмма компонентов (Component Diagram) – отображает
архитектуру проекта: из каких файлов и модулей состоит
веб-приложение (HTML, CSS, JS-модуль парсинга) и как они
связаны между собой и с внешним API.
2. Диаграмма развёртывания (Deployment Diagram) – показывает
физическое размещение компонентов системы: браузер
пользователя, веб-сервер, с которого отдаётся страница, и
сторонний API-сервер, с которого осуществляется парсинг данных.
Рекомендуемые источники данных (на выбор студента):
1. Открытые REST API (JSONPlaceholder, OpenWeatherMap,
CoinGecko, NewsAPI и др.)
2. Публичные каталоги и базы данных с поддержкой CORS
3. RSS-ленты новостных порталов
4. Любой другой публично доступный источник данных,
согласованный с преподавателем
