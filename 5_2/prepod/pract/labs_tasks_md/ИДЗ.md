ИНДИВИДУАЛЬНОЕ ДОМАШНЕЕ ЗАДАНИЕ
Тема: Разработка веб-страницы с элементами анимации и обработкой
данных. Верстка макета из Figma в HTML/CSS с интеграцией динамического
контента.
Цель работы
Изучить методы верстки веб-страниц, освоить преобразование макета
из Figma в HTML/CSS-код, а также приобрести практические навыки
добавления анимаций и обработки (парсинга) данных из локальных
источников для динамического наполнения веб-страницы с помощью
JavaScript.
Задание кафедры
Используя знания по HTML и CSS, сверстать веб-страницу по одному
из макетов, разработанных в среде Figma. Номер варианта определяется в
соответствии с номером студента в списке группы. Для разрабатываемой
страницы построить 3 диаграммы: IDEF0, классовую диаграмму и диаграмму
потоков данных (DFD).
Требования к выполнению задания:
1. Веб-страница должна быть сверстана по предоставленному макету из
среды Figma и содержать все предусмотренные элементы интерфейса:
заголовки различных уровней, текстовые блоки, списки, изображения,
кнопки и иные компоненты.
2. Верстка должна быть выполнена с использованием HTML5 и CSS3.
3. На странице должны быть реализованы анимации с использованием
CSS (или JavaScript при необходимости), обеспечивающие визуальную
интерактивность интерфейса (например, анимации кнопок, появления
элементов, наведения и др.).
4. Должен быть реализован механизм загрузки и обработки данных из
локального файла (например, в формате JSON), с последующей
подстановкой этих данных в соответствующие элементы страницы
вместо статического содержимого, предусмотренного макетом.
5. Все графические ресурсы должны быть корректно экспортированы из
Figma и подключены в проекте.
6. Веб-страница должна корректно отображаться в современных
браузерах.
7. При наличии нескольких макетов студент обязан уточнить у
преподавателя, какой именно вариант подлежит выполнению.
8. Все файлы проекта (HTML, CSS, JavaScript, а также используемые
ресурсы и файл с данными) должны быть предоставлены вместе с
отчетом.
Требования к отчёту
Отчёт по лабораторной работе должен содержать следующие разделы:
1. Титульный лист
2. Цель работы
3. Задание кафедры
4. Выполнение работы – скриншоты результата в браузере, листинг
HTML-, CSS- и JavaScript-кода, описание реализованных анимаций и
механизма загрузки данных, построенные диаграммы: IDEF0,
классовая диаграмма и диаграмма потоков данных (DFD).
