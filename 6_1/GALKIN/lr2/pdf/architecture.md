# Часть 1

### 1.1. Разработка справочников

Для хранения основных сведений об участниках учебного процесса и учебных объектах создаются следующие справочники.

**1. Справочник «Студенты»**

- Имя — ФИО студента, строка.
- НомерЗачетнойКнижки — строка.
- ДатаРождения — дата.
- УчебнаяГруппа — ссылка на справочник «УчебныеГруппы».

Ответственный за заполнение: администратор.

**2. Справочник «Преподаватели»**

- Имя — ФИО преподавателя, строка.
- Должность — строка.
- Квалификация — строка.

Ответственный за заполнение: администратор.

**3. Справочник «УчебныеГруппы»**

- Имя — название группы, строка.
- Курс — число.
- Факультет — строка.

Ответственный за заполнение: администратор.

**4. Справочник «Дисциплины»**

- Имя — название дисциплины, строка.
- КодДисциплины — строка.
- КоличествоЧасов — число.

Ответственный за заполнение: администратор.

**5. Справочник «Семестры»**

- Имя — название учебного периода, строка.
- УчебныйГод — строка.
- НомерСеместра — число.
- ДатаНачала — дата.
- ДатаОкончания — дата.

Ответственный за заполнение: администратор.

**6. Справочник «ПользователиИС»**

- Имя — ФИО пользователя, строка.
- Логин — строка.
- Роль — перечисление или строка (студент, преподаватель, администратор).
- Студент — ссылка на справочник «Студенты».
- Преподаватель — ссылка на справочник «Преподаватели».

Ответственный за заполнение: администратор.

### 1.2. Разработка документов

Документы предназначены для регистрации основных событий процесса учёта успеваемости.

**1. Документ «ВводОценок»**

Предназначен для регистрации оценок, выставляемых преподавателем.

Реквизиты шапки:

- Преподаватель — ссылка на справочник «Преподаватели».
- Семестр — ссылка на справочник «Семестры».

Табличная часть «Оценки»:

- Студент — ссылка на справочник «Студенты».
- Дисциплина — ссылка на справочник «Дисциплины».
- ДатаОценки — дата.
- Оценка — число.
- Комментарий — строка.

Показатели документа: количество выставленных оценок и значения оценок студентов.

**2. Документ «КорректировкаОценки»**

Предназначен для изменения ранее выставленных оценок.

Реквизиты шапки:

- Преподаватель — ссылка на справочник «Преподаватели».
- Семестр — ссылка на справочник «Семестры».
- ПричинаКорректировки — строка.

Табличная часть «Корректировки»:

Студент — ссылка на справочник «Студенты».

- Дисциплина — ссылка на справочник «Дисциплины».
- СтараяОценка — число.
- НоваяОценка — число.
- ДатаОценки — дата.

Показатели документа: старая и новая оценки, количество изменённых записей.

**3. Документ «НазначениеПреподавателя»**

Предназначен для закрепления преподавателей за дисциплинами и учебными группами.

Реквизиты шапки:

- Семестр — ссылка на справочник «Семестры».
- ДатаНазначения — дата.

Табличная часть «Назначения»:

- Преподаватель — ссылка на справочник «Преподаватели».
- Дисциплина — ссылка на справочник «Дисциплины».
- УчебнаяГруппа — ссылка на справочник «УчебныеГруппы».

Показатели документа: количество назначений преподавателей и перечень закреплённых за ними дисциплин и групп.

### 1.3. Разработка регистров накопления

Регистры накопления предназначены для хранения и обработки данных об оценках и результатах успеваемости студентов.

**1. Регистр накопления «ОценкиСтудентов»**

Вид регистра: **Обороты**.

Назначение: хранение информации о выставленных студентам оценках с возможностью анализа по дисциплинам, преподавателям и семестрам.

Измерения:

- Студент — ссылка на справочник «Студенты».
- Дисциплина — ссылка на справочник «Дисциплины».
- Преподаватель — ссылка на справочник «Преподаватели».
- Семестр — ссылка на справочник «Семестры».

Ресурсы:

- Баллы — число.
- КоличествоОценок — число.

Источники формирования движений:

- Документ «ВводОценок» — добавляет новые оценки.
- Документ «КорректировкаОценки» — корректирует ранее зарегистрированные значения.

**2. Регистр накопления «ИтогиУспеваемости»**

Вид регистра: **Обороты**.

Назначение: хранение агрегированных показателей успеваемости студентов для быстрого расчёта среднего балла.

Измерения:

- Студент — ссылка на справочник «Студенты».
- Дисциплина — ссылка на справочник «Дисциплины».
- Семестр — ссылка на справочник «Семестры».

Ресурсы:

- СуммаБаллов — число.
- КоличествоОценок — число.

Источники формирования движений:

- Документ «ВводОценок» — увеличивает сумму баллов и количество оценок.
- Документ «КорректировкаОценки» — изменяет сумму баллов и количество оценок с учётом старого и нового значений.

Средний балл рассчитывается как отношение суммы баллов к количеству оценок.

### Иерархическая структура конфигурации

В конфигураторе объекты будут организованы следующим образом:

- **Справочники**
  - Студенты
  - Преподаватели
  - УчебныеГруппы
  - Дисциплины
  - Семестры
  - ПользователиИС
- **Документы**
  - ВводОценок
  - КорректировкаОценки
  - НазначениеПреподавателя
- **Регистры накопления**
  - ОценкиСтудентов
  - ИтогиУспеваемости
- **Перечисления**
  - РолиПользователей (Студент, Преподаватель, Администратор)

Таким образом, разработанная структура конфигурации обеспечивает хранение сведений об участниках учебного процесса, регистрацию оценок, корректировку результатов и расчёт показателей успеваемости студентов.

### 2.2. Разработка механизмов проведения документов
Это основная часть этапа. Необходимо реализовать заполнение регистров накопления при проведении документов.

Документ	Действие при проведении
ВводОценок	Запись новых оценок в ОценкиСтудентов и обновление итоговых показателей в ИтогиУспеваемости
КорректировкаОценки	Отмена влияния старой оценки и запись новой
НазначениеПреподавателя	Фиксация назначения преподавателя, если для этого предусмотрен соответствующий регистр

Обработчик проведения документа ВводОценок находится здесь:

Документы → ВводОценок → Модуль объекта → ОбработкаПроведения.

Общий принцип реализации:

Процедура ОбработкаПроведения(Отказ, РежимПроведения)

    Для Каждого СтрокаОценки Из Оценки Цикл

        Движение = Движения.ОценкиСтудентов.Добавить();

        Движение.ВидДвижения = ВидДвиженияНакопления.Приход;
        Движение.Период = Дата;

        Движение.Студент = СтрокаОценки.Студент;
        Движение.Дисциплина = СтрокаОценки.Дисциплина;
        Движение.Оценка = СтрокаОценки.Оценка;

    КонецЦикла;

КонецПроцедуры

### 2.3. Реализация контроля и бизнес-логики

Вместо проверки остатков товаров реализуем проверки, соответствующие учёту успеваемости.

Проверки "на дурака" перед проведением:

Процедура ОбработкаПроведения(Отказ, РежимПроведения)

    Если Не ЗначениеЗаполнено(Преподаватель) Тогда
        Сообщить("Не указан преподаватель.");
        Отказ = Истина;
        Возврат;
    КонецЕсли;

    Если Не ЗначениеЗаполнено(Семестр) Тогда
        Сообщить("Не указан семестр.");
        Отказ = Истина;
        Возврат;
    КонецЕсли;

    Если Оценки.Количество() = 0 Тогда
        Сообщить("Не добавлено ни одной оценки.");
        Отказ = Истина;
        Возврат;
    КонецЕсли;

    Движения.ОценкиСтудентов.Записывать = Истина;

    Для Каждого СтрокаОценки Из Оценки Цикл

        Если Не ЗначениеЗаполнено(СтрокаОценки.Студент)
            Или Не ЗначениеЗаполнено(СтрокаОценки.Дисциплина) Тогда

            Сообщить("Не заполнен студент или дисциплина.");
            Отказ = Истина;
            Возврат;

        КонецЕсли;

        Если СтрокаОценки.Оценка < 1
            Или СтрокаОценки.Оценка > 5 Тогда

            Сообщить("Оценка должна находиться в диапазоне от 1 до 5.");
            Отказ = Истина;
            Возврат;

        КонецЕсли;

        Движение = Движения.ОценкиСтудентов.Добавить();

        Движение.Период = Дата;
        Движение.Студент = СтрокаОценки.Студент;
        Движение.Дисциплина = СтрокаОценки.Дисциплина;
        Движение.Преподаватель = Преподаватель;
        Движение.Семестр = Семестр;
        Движение.Баллы = СтрокаОценки.Оценка;
        Движение.КоличествоОценок = 1;

    КонецЦикла;

КонецПроцедуры
