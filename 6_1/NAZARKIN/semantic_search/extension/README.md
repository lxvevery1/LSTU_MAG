# WSB Semantic Search — браузерное расширение

Добавляет на страницы `reddit.com` плавающую панель семантического поиска. Запрос
уходит в локальный HTTP API (`semantic_search/server.py`), результаты показываются
прямо на странице: заголовок, год, flair, тикеры, косинусное сходство, score поста и
сниппет. Клик по результату открывает пост на Reddit в новой вкладке.

## Установка

1. Запустите локальный сервер (см. ниже).
2. Откройте `chrome://extensions` (или `edge://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку
   `semantic_search/extension`.
5. Откройте [reddit.com](https://www.reddit.com/) — панель появится в правом нижнем
   углу.

Поддерживаются Chromium-браузеры (Chrome, Edge, Brave, Yandex Browser, Opera) и
Firefox 121+: в манифесте объявлены оба варианта background (`scripts` и
`service_worker`), остальной код общий.

## Запуск сервера

```bash
cd semantic_search
source .venv/bin/activate
python server.py --host 127.0.0.1 --port 8000
```

Проверка, что API доступен:

```bash
curl -s http://127.0.0.1:8000/health
```

Расширение по умолчанию обращается к `http://127.0.0.1:8000`. Другой порт можно
указать в настройках расширения (иконка расширения на панели браузера или ссылка
«настройки» в футере панели поиска).

## Использование

| действие | результат |
|---|---|
| ввод запроса + `Enter` | поиск |
| `Alt`+`S` | фокус на поле поиска с любой страницы reddit.com |
| `Esc` в поле | свернуть панель |
| селектор `5/10/20/50` | сколько постов запросить у API (`top_k`) |
| клик по результату | открыть пост на Reddit в новой вкладке |
| ссылка «настройки» | страница настроек расширения |

Примеры запросов: `акции APPL`, `GameStop short squeeze`, `Tesla earnings`,
`NVDA AI chips`.

## Как это работает

```
┌──────────────────────── reddit.com (HTTPS) ────────────────────────┐
│ content.js                                                         │
│   shadow DOM панель (panel.css)                                    │
│   ввод запроса ──► chrome.runtime.connect (port "wsb-search")       │
└────────────────────────────────┬───────────────────────────────────┘
                                 │
┌────────────────────────────────▼───────────────────────────────────┐
│ background.js (service worker)                                     │
│   chrome.storage.local: serverUrl                                  │
│   fetch http://127.0.0.1:8000/search?q=...&top_k=...&normalize=1   │
└────────────────────────────────┬───────────────────────────────────┘
                                 │ JSON
┌────────────────────────────────▼───────────────────────────────────┐
│ server.py ──► Searcher ──► нормализация ──► энкодер ──► FAISS      │
│                                              └──► SQLite метаданные│
└────────────────────────────────────────────────────────────────────┘
```

Запрос выполняется в background service worker, а не в content script, по двум
причинам:

- страница Reddit открыта по HTTPS, а API — по HTTP; прямой запрос из контент-скрипта
  может блокироваться как mixed content;
- локальный сервер не отдаёт CORS-заголовки, а у service worker есть
  `host_permissions` для `localhost`/`127.0.0.1`, поэтому он может читать ответ.

Основной транспорт — долгоживущий порт `chrome.runtime.connect` (имя `wsb-search`):
он держит service worker активным на время запроса и надёжнее, чем одноразовый
`sendMessage` на некоторых сборках Chromium. `sendMessage` оставлен как fallback.

Сервер и его зависимости менять не нужно.

## Настройки

Страница настроек (`options.html`):

- адрес сервера (по умолчанию `http://127.0.0.1:8000`);
- кнопка проверки соединения — дергает `/health` и показывает модель и число векторов;
- сброс к значению по умолчанию.

Выбранное количество результатов (`top_k`) запоминается в `chrome.storage.local`.

## Структура

| файл | назначение |
|---|---|
| `manifest.json` | Manifest V3: content script, service worker, host permissions |
| `content.js` | панель в shadow DOM, рендер результатов, горячие клавиши |
| `panel.css` | стили панели (изолированы в shadow root) |
| `background.js` | HTTP-запросы к локальному API, обработка ошибок и таймаутов |
| `options.html` / `options.js` | настройки адреса сервера и проверка соединения |

## Ограничения и безопасность

- расширение работает только на домене `reddit.com` и обращается только к
  `localhost`/`127.0.0.1`; данные никуда наружу не отправляются;
- `host_permissions` намеренно ограничены локальным сервером. Если сервер запущен на
  другой машине в локальной сети, добавьте её адрес в `host_permissions` и разрешите
  его в `options.js` (`isLocalServer`);
- при перезагрузке расширения уже открытые вкладки теряют связь с background —
  обновите страницу;
- если панель не появилась, проверьте, что content script включён для `reddit.com`
  на странице расширения и что вы не находитесь в iframe.

## Диагностика

| симптом | причина / решение |
|---|---|
| красный индикатор, «Не удалось подключиться» | не запущен `server.py` или другой порт |
| `HTTP 400: missing q parameter` | пустой запрос (не должен возникать из UI) |
| «Расширение потеряло связь с фоновым процессом» | расширение перезагружали — обновите вкладку |
| панель без стилей | не загрузился `panel.css`; проверьте `web_accessible_resources` |
