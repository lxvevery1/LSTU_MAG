WSB Semantic Search

Панель поиска появляется на страницах reddit.com и обращается к локальному HTTP API семантического поиска.

По умолчанию http://127.0.0.1:8000. Расширение имеет доступ только к localhost и 127.0.0.1 (порт любой). 

—

Как запустить сервер

cd semantic_search
source .venv/bin/activate
python server.py --host 127.0.0.1 --port 8000

Использование

Откройте reddit.com: панель находится в правом нижнем углу. Запрос отправляется по Enter, панель сворачивается по Esc. Быстрый фокус на поле — Alt+S.
